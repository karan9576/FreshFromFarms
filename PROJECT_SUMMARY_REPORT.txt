1. EXECUTIVE OVERVIEW & BRAND POSITIONING
================================================================================
FreshFromFarms is a modern, direct-to-consumer (D2C) e-commerce web platform 
dedicated to 100% natural, GI-tagged, water-cultivated organic Makhana (Indian 
Fox Nuts / Lotus Seeds) sourced directly from the water fields of Bihar, India.

The application delivers an enterprise-grade shopping experience combining 3D 
interactive graphics, instant checkout, real-time cart persistence, automated email 
invoices, rich Google Shopping SEO integration, and robust cloud security.

4. BACKEND API ENDPOINTS, CONTROLLERS & DATA MODELS
================================================================================

DATA MODELS (`backend/models/`):
- `User.js`   : Stores Google ID, Email, Name, Hashed Password, Email Verification Status, 
                and Reset Tokens.
- `Product.js`: Stores Product Slug, Name, Price, Original Price, Description, Flavour, 
                Weight, Nutrition, Rating, and Stock.
- `Order.js`  : Stores User Ref, Email, Phone, Address Coordinates, Items Array, Total Amount, 
                Razorpay Order ID, Razorpay Payment ID, and Order Status.
- `Stat.js`   : Stores Date string (`YYYY-MM-DD`) and aggregated daily Revenue total.

API ENDPOINTS & CONTROLLERS (`backend/routes/` & `backend/controllers/`):

1. Auth Routes (`/api/auth`):
   - `POST /register`        : Registers new user and sends 6-digit OTP code email.
   - `POST /verify-email`    : Verifies 6-digit OTP code and activates account.
   - `POST /login`           : Authenticates user credentials via Passport Local strategy.
   - `GET  /google`          : Initiates Google OAuth 2.0 redirection flow.
   - `GET  /google/callback` : Handles Google OAuth callback and session creation.
   - `GET  /status`          : Returns current authenticated user profile state.
   - `POST /logout`          : Destroys user session cookie.

2. Product Routes (`/api/products`):
   - `GET  /`                : Fetches all available products from database.
   - `GET  /:id`             : Fetches single product details by ID or slug.

3. Payment Routes (`/api/payment`):
   - `POST /order`           : Creates official Razorpay Order via REST API.
   - `POST /verify`          : Verifies Razorpay HMAC SHA256 payment signature, saves order, 
                               increments daily revenue, and triggers invoice emails.

4. Admin Routes (`/api/admin`):
   - `GET  /stats`           : Aggregates total revenue, order count, and sales trends.
   - `GET  /orders`          : Lists all customer orders with filtering options.
   - `PUT  /orders/:id`      : Updates order status (`Shipped`, `Delivered`).
